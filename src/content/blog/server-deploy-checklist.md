部署完成不等于工作结束。至少还应该确认以下项目：

1. 服务是否设置开机启动；
2. 对外端口是否确实可访问；
3. 反向代理是否生成正确的 HTTPS 链接；
4. 日志与磁盘是否存在持续增长风险；
5. 上一个版本是否可以快速恢复。

对于静态网站，回滚通常只需要将 Web 根目录切换回上一份构建产物。
