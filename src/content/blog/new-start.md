今天，HolyLinux 正式迁移到 Astro。

之前的博客需要 Java 进程和数据库持续运行。新的版本在发布时生成普通的 HTML、CSS 和少量 JavaScript，访问文章时不再查询数据库。

## 为什么选择静态架构

对个人博客来说，最重要的不是复杂的功能，而是稳定地写作和保存内容。

- 页面加载更快；
- 服务器资源占用更少；
- 文章可以通过 Git 备份；
- 更换托管平台时更容易迁移。

接下来，这里会逐步记录 Linux、服务器和开发相关的实践。
